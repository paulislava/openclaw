# Исправленные ошибки

## 2026-10-28: старые пути Mac блокировали миграцию Codex

Симптом: Doctor отказывался переносить 488 sidecars, поскольку 213 записей старых `sessions.json` ссылались на `/Users/pkondratov/.openclaw/agents/...` после переноса состояния на Linux. Codex importer отклонял выход за каталог сессий до сопоставления sidecars.

Решение на данных: при остановленной службе сохранены точные копии восьми индексов и SHA-256. Только `sessionFile` для проверенного same-agent префикса заменён относительным basename. Проверены связь имени с `sessionId`, допустимые topic suffixes и отсутствие symlink escape. Отсутствующий JSONL допустим для sidecar-only migration. Sidecars, sessionId, ключи, lifecycle, harness и история SQLite не изменялись. Повторный Doctor сохранил штатные проверки владельцев и завершился с кодом 0.

Связанные исходники: `extensions/codex/src/migration/session-binding-legacy-index.ts`, `session-binding-owners.ts`, `session-binding-sidecars.ts`.

## 2026-10-28: устаревшее описание OpenAI отклоняло chat inference

Симптом: запрос к `openai/gpt-6-luna` завершался ошибкой `does not support chat inference`. Ручной transport/model overlay из старой конфигурации нарушал соответствие возможностей точному маршруту новой версии.

Решение: резервировать конфигурацию и удалить избыточный `models.providers.openai`, сохранив выбранные модели, Codex runtime и OAuth. Штатный discovery восстановил правильный маршрут. Один только переход адреса на `/codex` был недостаточен. Внутреннее `inference` нельзя добавлять в пользовательскую конфигурацию. Проверка: реальный запрос к прежней модели завершился ответом `OK`.

## Замечания upstream при обслуживании

Doctor выдавал `StateDatabaseMaintenanceScopeError` при фоновом idle close. Независимое ревью связало это с detached timer; финальное закрытие выполняется владельцем maintenance scope. Ошибка не остановила успешную миграцию. Исходники для этого предупреждения не изменялись.

На VPS с 3 ГБ RAM одновременная работа нового Gateway и тяжёлого CLI исчерпывала RAM и swap. CLI остановлен; дальнейшие проверки выполнялись лёгким RPC-клиентом. Параллельность агентов и субагентов ограничена двумя. Базовое потребление памяти требует наблюдения при реальной нагрузке.

## 2026-10-28: окружение CI и частичные mock-модули

CI `40608946015` обнаружил отсутствие `rg` на hosted runner и шесть mock factories, не сохранявших реальные экспорты. Перед main push ratchets добавлен существующий доверенный `setup-ripgrep`. В четырёх тестах `importOriginal` сохраняет реальные экспорты при прежних подменах; удалено одно устаревшее исключение baseline. Проверка mock policy и восемь тестов прошли; независимое ревью замечаний не обнаружило. Runtime приложения не изменялся.
