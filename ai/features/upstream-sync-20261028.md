# Обновление upstream и сохранение доработок

## Результат

Общее изменение личного форка перенесено на upstream `567053713e703dec162651e6e2a10c05b498cafa` от 2026-10-27. Версия OpenClaw изменилась с 2026.6.30 на 2026.10.7. Код обновления: `20bd43b0451e1bbe66a3df1b46d60daa9f93366b`.

Ветки `feat/telegram-rich-outbound`, `feat/compaction-via-claude-cli` и `feat/ios-lock-widget` уже входили в исходный main. Перенесён их общий результат вместе с сохранёнными серверными правками. Проверены все 129 исходных путей: 98 перенесены, 30 заменены реализацией upstream, один устаревший build lockfile удалён upstream. Пропущенных доработок не обнаружено.

Сохранены Telegram location/venue/video-note, CLI aliases и voice, происхождение пересланного сообщения, отсечение старых входящих сообщений, footer использования, compaction через Claude, native OAuth usage, workshop proposals, iOS Siesta и виджет блокировки. Реализация использует актуальные владельцы плагинов, SQLite и проверки полномочий после асинхронных операций.

## iOS Siesta

Сохранены имя, 29 иконок, deep links и lock widget. Локальная подпись и идентификаторы приложения, расширений и App Group остаются в игнорируемом `.local-signing.xcconfig`. Локальные include выполняются после Debug defaults. Проверены синтаксис Swift, plist и совпадение App Group; сборка и установка на физическое устройство не выполнялись.

## Обновление VPS

Сервер использует `/root/openclaw`, ветку `feature/upstream-sync-20261028` и службу `openclaw-gateway`. На сервере выполнен `git pull --ff-only --no-tags fork feature/upstream-sync-20261028`. Общий `/usr/bin/node` обновлён до 24.22.1.

Перед заменой сохранены состояние, старые артефакты, исходные незакоммиченные файлы, launcher и unit. Резервные копии находятся вне репозитория в закрытом каталоге `/root/backups/openclaw-20261028`. Launcher и wrapper используют штатный `openclaw.mjs`; существующее окружение wrapper сохранено.

Артефакты собраны на Mac командой `pnpm build`. На Linux установлены production-зависимости из frozen lockfile с `--ignore-scripts --package-import-method=hardlink`; Mac node_modules не переносились. Нативный Linux fs-safe 0.26.13 проверен штатным verifier и SHA-256. Связи зависимостей плагинов восстановлены штатными build helpers. Darwin addons в worker bundle сохранены как предусмотренные upstream кросс-платформенные payloads.

При ограниченном диске для pnpm 12 переносить завершённый кеш `files` вместе с его `index.db`, когда pnpm остановлен. Каталог кеша `links` не нужен при hardlink import. Частичное копирование кеша без его индекса вызывает повторные загрузки. После установки допустима штатная `pnpm store prune`; данные приложения и резервные копии не очищать.

Перед запуском после обновления выполнять `doctor --fix --non-interactive` при остановленной службе и проверять код завершения. Для перенесённых с Mac старых индексов см. [устранённые ошибки](../ERRORS.md). Миграция завершилась с кодом 0: перенесены 487 Codex sidecars; один сохранён для владельца harness `openclaw`.

Устаревший ручной `models.providers.openai` удалён после резервирования конфигурации. Выбор моделей, per-model Codex runtime и OAuth сохранены; каталог и адреса получает штатный discovery. В пользовательские model definitions не добавлять `inference`: это внутреннее поле каталога. Для VPS с 2 CPU и 3 ГБ RAM установлены `agents.defaults.maxConcurrent=2` и `agents.defaults.subagents.maxConcurrent=2`. Тяжёлые CLI-команды обслуживания не запускать одновременно с Gateway на этом VPS.

## Проверки и ограничения

Полная локальная сборка, typecheck, scoped lint и целевые тесты прошли. Штатный native i18n baseline дополнен 14 строками сохранённого lock UI; `pnpm native:i18n:verify` прошёл для 4532 записей. Независимое ревью завершено без открытых замечаний. На Linux проверены нативный модуль, запуск 2026.10.7 и `/healthz` 200. Реальный запрос к `main` через native Codex на прежней `gpt-6-luna` завершился успешно с ответом `OK`; внешняя доставка была выключена. Сайт отвечает 200.

API блокировки возвращает 401 без токена и с неверным токеном; с правильным токеном backend возвращает 502. Управляющие POST-запросы не выполнялись. WhatsApp требует повторной авторизации, Mattermost API недоступен; эти два состояния подтверждены журналами до обновления. Поэтому общий `/readyz` не считается успешным функциональным тестом всех каналов.

Для кода `20bd43b` CodeQL и Workflow Sanity завершились успешно. Основной CI `40600382501` отменён; зелёный результат основного CI не подтверждён. Локальная сборка и серверные проверки фиксируются отдельно от CI и проверки iOS на устройстве.

Дополнительный CI для `7663e3f` выявил отсутствие ripgrep на runner и несовместимые partial mocks. Исправлены подготовка CI, шесть mock factories и одно устаревшее исключение. Локальная проверка mock policy и восемь тестов в четырёх файлах прошли; узкое независимое ревью завершено без замечаний. Изменения не затрагивают runtime артефакты сервера.
